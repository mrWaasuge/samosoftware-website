# SamoSoftware.com - React Project

This is the source code for the SamoSoftware.com website, built with **React** and **Vite**.

## Prerequisites
- **Node.js**: You must have Node.js installed on your computer. Download it from [nodejs.org](https://nodejs.org/).

## Getting Started

1.  **Open Terminal**: Open a command prompt or terminal in this folder (`c:\Users\hp\Desktop\my_web`).
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Run Development Server**:
    ```bash
    npm run dev
    ```
4.  **Open in Browser**:
    Click the link provided in the terminal (usually `http://localhost:5173`).

## Project Structure
- `src/components`: Reusable UI components like Header and Footer.
- `src/pages`: Page content components.
- `src/index.css`: Global styles.

## Build for Production
To generate a production build:
```bash
npm run build
```
The output will be in the `dist` folder.
